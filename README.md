# Русификатор интерфейса Antigravity (Движок V5)

Автономный патчер для перевода интерфейса среды **Antigravity** на русский язык. 

Никакого Node.js, компиляторов и танцев с бубном в терминале: всё запаковано в один `.exe` файл, который сам находит установленную программу, делает резервную копию и накатывает перевод за пару секунд.

---

## Что внутри

* **Словарь на 2140+ строк:** переведены настройки, боковая панель, меню, диалоговые окна, статусы агента и горячие клавиши.
* **Паттерны и регулярки:** динамические системные сообщения и переменные подставляются корректно, без ломания разметки.
* **Автопоиск папки:** утилита сама находит Antigravity (в стандартном `%LOCALAPPDATA%`, `Program Files`, через реестр или по запущенному процессу).
* **Безопасность и бэкапы:** перед любым вмешательством делается проверенная копия `app.asar` в `%LOCALAPPDATA%\NEXUS_Tools\backups` (хранятся последние 5 версий). Если что-то пойдёт не так — откат происходит автоматически.

---

## Быстрый старт (Установка за 4 шага)

1. **Полностью закройте Antigravity.**  
   Обязательно проверьте значок в трее Windows (возле часов): правый клик → *Выход*. Если программа открыта, патчер не сможет перезаписать занятый файл.
2. Скачайте актуальный файл [**Русификатор Antigravity.exe**](https://github.com/nexus-network-lab/Antigravity-Russifier/releases/download/v5.0/Antigravity_Russifier.exe) (или возьмите напрямую из репозитория).
3. Запустите `Русификатор Antigravity.exe`.
4. В появившемся консольном меню нажмите клавишу **`1`** (Установить).
5. Запустите Antigravity — интерфейс уже на русском.

> **Как вернуть английский язык обратно:**  
> Запустите файл ещё раз и нажмите **`2`** (Убрать). Патчер восстановит оригинальный `app.asar` из резервной копии.

---

## Что делать, если Antigravity обновилась?

Разработчики Antigravity периодически выпускают обновления, при которых файл `app.asar` перезаписывается на стандартный английский.

**Решение простое:** после обновления снова запустите `Русификатор Antigravity.exe` и нажмите `1`.

---

## Работа из консоли / Автоматизация (CLI)

Для запуска из батников, скриптов или планировщика задач предусмотрены флаги:

* `--apply` — применить русификацию без вызова интерактивного меню;
* `--remove` — откатить изменения и вернуть оригинальный файл;
* `--status` — проверить, русифицирована ли текущая версия;
* `--dir "C:\Путь\К\Antigravity"` — указать нестандартную папку установки вручную.

Пример:
```cmd
"Русификатор Antigravity.exe" --apply
```

## Для разработчиков (Сборка из исходников)

Если хотите дополнить словарь или собрать `.exe` самостоятельно:

* Вся логика инъекции и парсинга лежит в папке `src/`:
  * `src/base/dictionary.ru.json` — основной словарь терминов.
  * `src/base/dictionary.patterns.ru.json` — регулярные выражения для динамических фраз.
  * `src/russify_antigravity.js` — скрипт распаковки и модификации `app.asar`.
* Оболочка лаунчера написана на Go (`go-launcher/`).
* Для сборки запустите `BUILD.bat` (требуются установленные `node.exe` и `go`).
